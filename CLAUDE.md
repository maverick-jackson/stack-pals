# stack-pals

Original counting game (Vite + TypeScript, no framework, SVG). Replaces the old Scratch-packaged
numberblocks-tablet build for a friend's kids; possible future PNL-Learn kids section.

- Original characters and palette only. Do not copy Numberblocks names, colors, or character traits.
- Layout logic lives in src/numbers.ts (pure, unit tested); src/character.ts draws it.
- Keep it light for low-end tablets: no audio files, no images beyond icons, animate transforms only.
- dist/sw.js is generated by scripts/gen-sw.mjs at build time and precaches every built file.
- Deploy: push to main; GitHub Actions builds and publishes to Pages.
