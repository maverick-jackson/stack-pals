# Stack Pals

A counting game for little kids. Pick a number from 0 to 100 and meet the block buddy made of
that many blocks. Tap the buddy to hear its name, count along block by block, or hit Surprise.

- Up to ten, a buddy is one tower. Past ten, every full ten stands as its own amber column and
  the ones stand beside it, so the shape shows place value.
- Every sound is synthesised and the number names use the device's speech voice, so there is
  nothing heavy to download. The whole app is about 40 KB and works offline once loaded.
- Installable: open it in Chrome or Safari and choose Add to Home Screen.

## Develop

```bash
npm install
npm run dev
npm test
npm run build
```

Pushing to `main` runs the tests, builds, and deploys to GitHub Pages.
